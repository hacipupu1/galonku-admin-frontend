# GalonKu Admin — Produk & Stok

Implementasi React + Vite dari tampilan Figma yang diberikan.

## Menjalankan
1. Pastikan Node.js sudah terpasang.
2. Buka folder project di VS Code.
3. Jalankan:
   npm install
4. Lalu:
   npm run dev
5. Buka URL Vite yang muncul di terminal.

## Fitur yang sudah aktif
- Sidebar berpindah halaman: Dashboard, Manajemen Pesanan, Produk & Stok, Monitoring Pengantaran, Laporan Keuangan.
- Search produk/SKU.
- Filter kategori.
- Tambah produk baru melalui modal.
- Update stok +1 / -1.
- Tombol restok +5.
- Status stok otomatis.
- Popover notifikasi.
- Filter periode tanggal.
- Detail produk.
- Cetak manifest menggunakan browser print.
- Responsive untuk desktop/tablet/mobile.
- Color palette sesuai screenshot: #0052FF, #131B2E, #E8F1FF, #FFFFFF, #28A745.
- Font utama: Inter.
